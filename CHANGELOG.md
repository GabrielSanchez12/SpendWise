# Changelog

## [1.0.0] - 17-05-2026

### Added
- Initial version of SpendWise CLI.
- Added expense registration.
- Added expense listing.
- Added expense removal.
- Added total spending calculation.
- Added spending summary by category.
- Added JSON data persistence.
- Added automated tests with Pytest.
- Added static analysis with Ruff.
- Added CI workflow with GitHub Actions.

## [2.0.0] - 11-06-2026

### Added
- Integração com banco de dados em nuvem usando Supabase.
- Persistência real de despesas em tabela PostgreSQL.
- Leitura, cadastro e remoção de despesas via banco de dados.
